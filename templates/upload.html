INTEGRA FILE SECURITY

De tu app al SDK.

PYTHON

El mismo flujo de escaneo que utiliza esta demo.

import json
import os
import amaas.grpc

handle = amaas.grpc.init_by_region(
    region=os.environ["V1_REGION"],
    api_key=os.environ["V1_API_KEY"],
)
try:
    response = amaas.grpc.scan_file(
        handle,
        file_name="documento.pdf",
        pml=True,
    )
    result = json.loads(response)
    print(json.dumps(result, indent=2))
finally:
    amaas.grpc.quit(handle)

Credenciales en variables de entorno. La respuesta JSON contiene el resultado del análisis.
